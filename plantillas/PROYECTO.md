# Contexto del proyecto

Plantilla para adaptar al archivo de instrucciones propio del proyecto. Completa
solo lo que aporte información; elimina campos vacíos. No copies la doctrina.

- Objetivo y usuarios: qué problema resuelve y para quién.
- Criterios de aceptación: qué resultados observables definen una entrega correcta.
- Arquitectura actual: componentes relevantes y sus responsabilidades.
- Fuentes canónicas: dónde consultar datos, decisiones y estado vigente.
- Restricciones: compatibilidad, rendimiento, presupuesto y decisiones ya tomadas.
- Verificación: comandos reales de pruebas y cómo recorrer el flujo afectado.
- Operación: cómo iniciar el entorno y distinguir prueba de producción.

Usa `AGENTS.md` para instrucciones de Codex y `CLAUDE.md` para Claude. Si ambos
consumen el contexto, mantén el contenido específico en un solo archivo y haz que
cada entrada lo lea mediante el mecanismo correspondiente. No asumas que la sintaxis
de importación de una herramienta funciona en la otra.
